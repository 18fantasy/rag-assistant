# 改动史（为什么这么改）

> **用途**：`git log` 只记“改了什么”，这份记“**为什么改**、**代价是什么**”。
> **规则**：每次改动追加一条，最新的在最上面。**只记“结构性改动”，不记改错别字。**

## 2026-11-08 · 清 P0-8：8 处同项目文件互相引用写死绝对路径

| 项 | 内容 |
|---|---|
| **发现者** | **学生**（他问「检索里面的地址还是只有我电脑的地址，换到别人电脑不需要改吗」）——**我照 P0 清单逐条对，只想到“数据目录”，漏了“同项目文件引用”这一类** |
| **问题** | `检索.py:4`／`问答.py:11`／`材料实验.py:6`／`eval/评测.py:14`／`eval/基线.py:9,10,15,57` 共 8 处写死 `C:/Users/2/...` |
| **改法** | 统一 `这里 = os.path.dirname(os.path.abspath(__file__))` ＋ `os.path.join(这里, "目标.py")`；`eval/` 在子目录，套两层 `dirname` |
| **代价** | 多 2 行代码；IDE 会标“未解析的引用”（动态模块推断不出，不影响运行） |
| **验证** | `自检.py` 第 1 项 8→0；整个项目拷到 `/tmp/rag_copy` 运行通过 |

**踩到的坑**：`问答.py` 第一次写成 `os.path.abspath(__file__)`（漏了 `dirname`）→ 路径变成 `...\问答.py\检索.py` → `FileNotFoundError`。**判据：路径里出现 `.py\xxx.py` 就是少了一层 `dirname`。**

## 2026-11-08 · 清顶层副作用 3 处

| 位置 | 改法 | 为什么 |
|---|---|---|
| `检索.py:11` | 删掉顶格 `print("载入块数")` | 加载就打印，污染评测输出 |
| `问答.py:5~10` | key 检查包进 `def 取头部()`，`headers=headers` → `headers=取头部()` | **加载时 `SystemExit` 会杀掉借用方（评测.py）**，改成调用时才 `RuntimeError`，可被捕获 |
| `api.py` | 整体包进 `if __name__ == "__main__":` | `import api` 会真的发一次 API 请求（花钱） |

**判据**：**“会不会被别人 import”决定要不要保护，与“在数据流第几环”无关。**
`问答.py` 在数据流是终点，但在依赖流是起点（评测/基线都加载它）。

## 2026-11-07 · 清 P0-1／P0-2（一半）：路径可配 ＋ 建索引收进函数

| 项 | 内容 |
|---|---|
| **问题** | `项目三号.py` 顶层扫盘 → 加载 1.4 秒 ＋ 刷 11 行输出；路径写死在第 3 行 |
| **改法** | ① `根目录 = os.environ.get("RAG_ROOT", 默认值)`；② 扫盘收进 `def 扫文件(根目录)`；③ 新增 `def 建索引(根目录)` 返回 `(全部块, 文件数)`；④ 主流程包进 `if __name__`；⑤ `检索.py:7` 从 `三号.全部块` 改成 `三号.建索引(三号.根目录)[0]` |
| **代价** | **`检索.py` 必须同步改**（内存级变量 → 函数调用），否则 `AttributeError: module '三号' has no attribute '全部块'` |
| **验证** | 加载 1.4s → **0.00s**；`RAG_ROOT=/tmp/ragtest` 生效（1 个文件 1 块） |

**核心认知**：**模块级变量 = 加载时就算；函数 = 调用时才算。** 想省掉“加载时”的开销，必须把供数据的方式改成函数——**代价是调用方要多写一行。**

## 2026-11-05 · 评测体系重建 ＋ 发现“索引污染”

| 项 | 内容 |
|---|---|
| **问题** | 16/20 是个孤立数字；判定列全空；题库/脚本版本脱节 |
| **改法** | 题库加版本号；`评测.py` 支持版本参数；产出「成绩单」（四件套＋逐题依据） |
| **关键发现** | **评测产物（成绩单/跑批原始）和题目文件都进了索引** → 模型照抄材料里的 `[编号2]` 格式；`评测题.md` 进索引等于**泄题** |
| **修复** | 全部移入 `eval/`，切块器排除该目录 |
| **结果** | 出处 8/16 → **16/16**；答对 16/20 → **18/20**；检索漏 3 → **0** |

**核心认知**：**观测者效应**——跑评测产生的文件，反过来污染下次检索。**索引目录里只能放“要被检索的内容”。**
